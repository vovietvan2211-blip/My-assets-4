Put your cat GIFs in this folder.

The names must match "gif" in ../../reactions.json, for example:
  popcat.gif  nyan.gif  keyboard.gif  grumpy.gif
  maxwell.gif banana.gif crying.gif   huh.gif

- A reaction whose file is missing shows its fallback emoji instead (so nothing breaks).
- Keep each GIF small (under ~500 KB, ideally ~200 px wide). Big GIFs make the host screen laggy.
- You can also use a direct https link in reactions.json instead of a file ("gif": "https://..."),
  but links on other websites can break or get blocked, so local files are safer.
- To add or remove a reaction, edit reactions.json (max 12). "id" must be lowercase letters/numbers.
